# تطبيق مواقيت الصلاة — مشروع Android (Kotlin)

هذا مشروع Android Studio مستوحى من ملف HTML المرفق. الحد الأدنى Android 8.0 (API 26)، وهدف البناء API 34، ويستخدم Android SDK 35 وJDK 17 وGradle 8.9.

## الحصول على ملف APK عبر GitHub Actions (من الهاتف أو الكمبيوتر)

> لا تحتاج إلى تثبيت Android Studio أو Android SDK على هاتفك. لكن يلزم حساب GitHub ورفع ملفات المشروع إلى مستودع تملكه؛ لا يمكن تشغيل GitHub Actions من ملف ZIP محلي وحده.

1. نزّل ملف `PrayerTimesAndroid-project.zip` وفك ضغطه باستخدام تطبيق الملفات على هاتفك.
2. افتح https://github.com وسجّل الدخول.
3. أنشئ مستودعًا جديدًا عبر **New repository**، واختر اسمًا مثل `PrayerTimesAndroid`، واجعله **Private** أو **Public**، ثم أنشئه.
4. افتح المستودع واضغط **Add file → Upload files**.
5. ارفع محتويات المجلد الداخلي `PrayerTimesAndroid`، بما فيها المجلد المخفي `.github` (وهو الذي يحتوي على تعليمات البناء). لا ترفع ملف ZIP وحده ولا تضع مجلد `PrayerTimesAndroid` داخل مجلد آخر بالمستودع.
6. اضغط **Commit changes** وانتظر ظهور الملفات في المستودع.
7. افتح تبويب **Actions**. إذا طلب GitHub تفعيل Actions، وافق على ذلك.
8. اختر سير العمل **Build Android APK** من القائمة الجانبية، ثم اضغط **Run workflow → Run workflow**.
9. افتح عملية التشغيل التي ظهرت حديثًا. انتظر حتى تصبح النتيجة خضراء **Success**.
10. انزل إلى قسم **Artifacts** في أسفل صفحة التشغيل، واضغط `prayer-times-debug-apk` لتنزيل ملف ZIP يحتوي على `app-debug.apk`.
11. فك ضغط ملف Artifacts على الهاتف، ثم افتح `app-debug.apk` وثبّته. اسمح بالتثبيت من هذا المصدر إذا طلب Android ذلك.

إذا لم يظهر سير العمل في Actions، فتأكد من أنك رفعت المجلد `.github/workflows/build-apk.yml` إلى جذر المستودع، ثم أعد تحميل صفحة Actions.

## ماذا يفعل سير العمل؟

- يعمل عند الضغط اليدوي على **Run workflow**، وكذلك عند دفع تغييرات إلى فرع `main` أو `master`.
- يجهز JDK 17 وAndroid SDK Platform 35 وBuild Tools 35.0.0 وGradle 8.9.
- ينفذ `gradle --no-daemon assembleDebug`.
- يرفع `app/build/outputs/apk/debug/app-debug.apk` كـ Artifact باسم `prayer-times-debug-apk`.

## بناء APK محليًا

من مجلد المشروع، مع تثبيت JDK 17 وAndroid SDK 35 وGradle 8.9:

```bash
gradle --no-daemon assembleDebug
```

مسار الملف الناتج:

`app/build/outputs/apk/debug/app-debug.apk`

## التثبيت والإعداد

1. افتح ملف APK على هاتف Android وثبّته.
2. اسمح بالإشعارات.
3. فعّل صلاحية التنبيهات/المنبهات الدقيقة (Exact Alarms) من إعدادات النظام إذا طُلب ذلك.
4. اسمح بإشعارات ملء الشاشة إن ظهر الخيار في إصدار Android لديك.
5. فعّل «العرض فوق التطبيقات الأخرى» إذا كان جهازك يتيح ذلك.
6. استثنِ التطبيق من تحسين البطارية/توفير الطاقة.
7. اختر المدينة أو «موقعي الحالي»، وراجع طريقة الحساب والمذهب، ثم فعّل تنبيهات الصلوات المطلوبة.
8. استخدم «تجربة الشاشة السوداء» لاختبار واجهة التنبيه يدويًا.

## ملاحظات مهمة

- التنبيهات المجدولة تستخدم `AlarmManager.setAlarmClock()`، وتُعاد جدولة التنبيهات بعد الإقلاع وتغيير الوقت/المنطقة الزمنية وتحديث التطبيق.
- تُعرض شاشة الصلاة عبر إشعار عالي الأولوية مع Full-Screen Intent. Android 14 وما بعده وبعض واجهات الشركات قد تقيّد عرض ملء الشاشة أو تشغيل Activity من الخلفية؛ لذلك لا يمكن ضمان الظهور فوق كل التطبيقات على كل هاتف.
- صلاحية «العرض فوق التطبيقات» لا تعني تلقائيًا السماح بفتح Activity من الخلفية، ولا يستخدم المشروع نافذة overlay دائمة تغطي التطبيقات.
- «موقعي الحالي» يعتمد على آخر موقع معروف من مزوّد GPS/الشبكة بعد منح إذن الموقع.
- حساب المواقيت يعمل دون إنترنت، لكن ينبغي مراجعة النتائج مع جهة موثوقة محليًا.
- لم يُختبر المشروع على هاتف فعلي أو محاكي في بيئة الإنشاء الحالية. نجاح بناء APK لا يثبت وحده أن التنبيه سيظهر والهاتف مقفل؛ يلزم اختبار فعلي على الجهاز.
